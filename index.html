The Four Pillars of MTPO

The core structural mechanisms that eliminate thread stalls and race conditions at the bare-metal level.

1. Monotonic Ranks (σ)

Every swarm agent is assigned an immutable monotonic rank ($\sigma_1 < \sigma_2 < \sigma_3$) at instantiation, establishing a logical timeline independent of physical arrival.

2. Order-Filtered Reads

Agent $A_j$ reads only writes committed by agents with rank $\le \sigma(A_j)$, screening out speculative noise and maintaining monotonic read isolation.

3. 3-Phase Saga Inverses

Every write registers a deterministic 3-phase undo (*Prepare, Execute, Reverse*). Lower-rank writes arriving late invert higher-rank state via $\Delta^{-1}$ and replay cleanly.

4. Non-Blocking Advisories (ν)

When an active premise is invalidated, runtime pushes advisory signal $\nu_{i \to j}$ into the prompt context. The agent repairs in-situ with zero token discard.
